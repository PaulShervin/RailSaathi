## 1. Objective

## 3. Implemented Capabilities

1. **Typed Data Models (`backend/journey/models.py`)**:
   - `TripRequirements`, `ResolvedLocation`, `StationCandidate`, `LastMileEstimate`, `TrainService`, `JourneyEvaluation`, `BookingHandoff`, `JourneyPlanResponse`.
2. **Location & Station Resolution Service (`backend/journey/location.py`)**:
   - Verified hub & venue registry (Tidel Park, IIT Madras, BKC Mumbai, HITEC City, etc.).
   - Station candidate discovery for departure and arrival metro areas.
   - Deterministic last-mile transit duration and distance calculations using Haversine and urban traffic modeling.
3. **Authoritative Timetable & Fare Service (`backend/journey/timetable.py`)**:
   - Verified Indian Railways schedules across major corridors (Bengaluru ↔ Chennai, Bengaluru ↔ Hyderabad, Delhi ↔ Mumbai, Delhi ↔ Bengaluru).
   - Real train numbers, run days, class allocations, and fare tables with data provenance tracking.
4. **Deterministic Feasibility Evaluator (`backend/journey/feasibility.py`)**:
   - Strict deadline formula: `latest_acceptable_station_arrival = meeting_start - requested_buffer - estimated_last_mile_duration`.
   - Overnight journey handling (`day_offset = 1/2`), midnight crossings, and hard constraint validation without double-subtraction.
5. **Recommendation & Ranking Engine (`backend/journey/ranking.py`)**:
   - Transparent deterministic scoring formula: base feasibility (100) + optimal buffer bonus (up to 25) + preferred train match (+35) + preferred class match (+20) + duration bonus + budget savings.
   - Isolates infeasible options in a dedicated section with explicit constraint violation reasons.
6. **Booking Handoff Service (`backend/journey/booking.py`)**:
   - Strict hostname allowlist (`www.irctc.co.in`, `enquiry.indianrail.gov.in`, `confirmtkt.com`).
   - Generates pre-formatted search handoff links with safe disclaimers.
7. **Unified Tool Registry & Agent Controller Integration (`backend/tools/registry.py`, `backend/tools/journey_tools.py`)**:
   - Unified all 13 tools with function calling for Gemini SDK and `DevMockGeminiClient`.
8. **Flask REST API Endpoints (`backend/app.py`)**:
   - `POST /api/journey/plan`: Natural language prompt or structured parameters.
   - `POST /api/journey/refine`: Re-evaluates plans with modified constraints.
   - `GET /api/journey/options/<request_id>`: Retrieves cached journey evaluation.
   - `GET /api/health`: Exposes health and 13 available tools.
9. **Dual-Mode React Frontend (`frontend/src/App.jsx`, `frontend/src/App.css`)**:
   - Tabbed view: 🎯 Goal Journey Planner and 💬 Ticketing Guidance.
   - Interactive journey visualizer with connected timeline nodes (Departure → In-transit → Station Arrival → Last-mile cab → Venue Arrival → Buffer Window → Meeting Start).
   - Best Match Hero card, Feasible Alternatives, Infeasible Options with constraint breach badges, and quick refiners.
